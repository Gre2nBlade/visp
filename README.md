# Visp

Visp — кроссплатформенный клиент VPN и прокси с кодами доступа, плагинами и Studio для владельцев собственной инфраструктуры. Проект рассчитан на личное использование, команды и компании, которым нужен контроль над серверами, конфигурациями и выдачей доступа.

## Возможности

- Импорт `visp://`, управляемых `VISP-...`, ссылок протоколов, подписок, QR и файлов.
- Studio для self-hosted серверов: установка подписанного агента, контроль компонентов, выпуск и отзыв кодов, лимиты устройств, сессий и трафика.
- Control Plane API как мост между Studio и агентами владельца. Можно размещать его у себя или использовать управляемый вариант.
- Плагины для протоколов, прокси, DNS-провайдеров и интеграций. Прокси появляются в Studio после установки плагина.
- DNS через системный resolver, DoH/DoT или туннель; WARP как дополнительный участок цепочки при поддержке ОС и маршрута.
- Стабильный и beta-каналы для приложения, движков и плагинов.
- Blup Visp на главном экране: движущийся периметр показывает состояние подключения и не подменяет текстовый статус.

## Модель безопасности

Агент устанавливает исходящее соединение с Control Plane, поэтому для управления не нужен открытый входящий порт. Команды и пакеты проверяются по подписи. Секреты протоколов не попадают в журналы, коды имеют срок и лимиты, а действия владельцев и сотрудников записываются в аудит.

Visp не обещает анонимность, неизменяемую геолокацию или обход любой блокировки. DNS, WARP, VPN и прокси имеют разные свойства; интерфейс показывает состояние каждого участка.

## Клиент (Flutter)

Клиент реализован на Flutter по дизайн-системе [DESIGN.md](DESIGN.md) —
адаптация токенов shadcn/ui (семантические роли, OKLCH-нейтральность slate,
ring-фокус) с направлением Minimalism & Swiss Style:

- `lib/core` — тема (`VispTheme`, shadcn-токены цветов, типографика, отступы, радиусы), адаптер иконок `VispIcon`, базовые компоненты (кнопка, поле ввода, карточка, чип, переключатель, строка списка, тост) и `BlupVisp` — фигура состояния с движущимся периметром;
- `lib/features` — главный экран с селектором протокола, добавление подключения и импорт кодов (vless://, hysteria2://, olcrtc://, WireGuard/AmneziaWG .conf), вкладка серверов и карточка сервера, настройки, Studio, плагины, прокси для Telegram, плавающая навигация;
- `lib/state` — состояние приложения, mock-движок VPN и сохраняемые предпочтения;
- `lib/l10n` — строки русского и английского языков.

Стартовый набор протоколов (раздел 3): AmneziaWG, Hysteria 2, olcRTC, XRay VLESS/REALITY.
Профиль импортируется и сохраняется даже без движка; состояние движка
(`EngineState`) показывается чипом, докачка имитируется при первом подключении.

```bash
flutter pub get
flutter run -d windows          # android, ios, macos, linux
flutter test                    # 14 тестов
flutter analyze

flutter build apk --debug       # build\app\outputs\flutter-apk\app-debug.apk
```

Подключение и измерения в этой версии — прототип движка: реальные движки
AmneziaWG, Hysteria 2, olcRTC и XRay подключаются как нативные плагины
(gomobile/VPN service) следующей фазой (раздел 3).
